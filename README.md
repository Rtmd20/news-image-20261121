# THE WORLD IN ONE DAY — Saturday 21 November 2026

A single 1024×1024 broadsheet front page summing up Saturday 21 November 2026's world news: 33 stories across 6 regions, each dated to that Saturday and named with a real source.

The program (`main.ts`, Node 22, standard library only, no network, deterministic) draws the whole page itself — masthead, date headline, KPI strip, region bar, 13 original flat-drawn story cards, a numbered world map, 20 more briefs, and a DATE CHECK box naming what was excluded and why — and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png`.

Facts were checked against the outlets named beside each story. The counts the top entries got wrong are right here: 3 Houthi missiles stopped over Riyadh (not 5), Kryvyi Rih 2 killed and 60 hurt as reported on Saturday, the Peru 6.7 quake with no casualties, COP31 in overtime with no deal yet (its collapse came Sunday), and the Indonesia factory fire at 3 dead and 36 missing as reported on Saturday.
